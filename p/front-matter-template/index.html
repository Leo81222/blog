Front Matter 完整字段模板说明

本站文章的 front matter 全字段参考模板：标题、日期、分类、标签、摘要、封面、版权等，写新文章时复制此文件改内容即可。

2026年11月5日 阅读时长: 1 分钟

这是模板文

本文章本身是「完整字段模板」的实例，写新文章时建议复制本文件，然后逐项替换：

字段含义说明
title标题文章主标题
description摘要用于列表页与 SEO 描述
date发布日期格式 YYYY-MM-DDTHH:MM:SS+08:00
lastmod最后修改可选
slugURL 别名最终地址为 /p/<slug>/
categories分类一篇文章建议只放一个主分类
tags标签可多个
keywords关键词可选，利于 SEO
draft草稿true 时本地可见、构建时不发布
image封面图留空则不显示封面
style分类卡片配色仅对分类页面生效

常用命令

# 新建文章
hugo new content post/my-writeup.md

# 本地预览（含草稿）
hugo server --buildDrafts

后续内容按正常 Markdown 编写即可。
